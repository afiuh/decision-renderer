# 渲染

**父级**：[决策网络渲染器](../决策网络渲染器.md)

## 约束

### 节点卡片

- 显示标题 + 状态标记（✅/⏳/❌/无）。
- 尺寸由内容决定；渲染层把真实宽高报给布局层，只有一个来源。
- 折叠的节点显示子节点数。

### 连线

- 父 → 子，方向不可逆。
- **边到边**：从父卡片边缘出发，到子卡片边缘结束，不穿过任何卡片。
- **最底层**：线在节点和内容节点之下。
- 贝塞尔曲线，细线。长度由布局给的半径决定，不单独算。

### 内容节点

- 点节点 → 在画布内展开内容节点（不是弹窗、不是侧栏）。
- 用 `parentId` 跟随原节点，随画布缩放，可拖拽、可缩放。
- 默认放在父节点外侧（远离根的方向），避免盖住子树。
- Markdown 渲染：标题、表格、链接、代码高亮。

## 边界

- **画布不读文件**。所有数据来自解析结果 / 接口。
- **不用弹窗/侧栏看内容**。内容必须和树在同一空间，否则看内容时丢了上下文。
- **不在渲染层算布局**。渲染只消费坐标。
- 不做节点内嵌子节点（卡片里再画树）。展开就是画布上的展开。

## 验证

- 任意缩放下，内容节点与父节点相对位置不变。
- 连线不穿过任何卡片（含内容节点）。
- 点开三个节点，三个内容节点互不重叠、不盖住被点的节点。
