# 真源与解析

**父级**：[决策网络渲染器](../决策网络渲染器.md)

## 约束

目录结构就是数据。解析只是把它读出来，不加解释。

- **一个 `.md` = 一个节点**。文件名去掉 `.md` 就是节点名。
- **`X.md` 与 `X-子节点/` 并列**。`X-子节点/` 里的每个文件/目录都是 `X` 的子节点。
- **节点 id = 相对工作区根的路径**。id 唯一，且可逆：能从 id 走回文件。
- **标题取正文第一个 `# `**；没有标题时退回文件名。
- **状态从正文提取**：`## 状态` 段或 `✅/⏳/❌` 标记。提取不到就是"无状态"，不猜。
- **归档区只读**：`历史讨论-子节点/` 这类目录解析出来但不参与演化，默认折叠。
- **工作区 = 一个决策网络根目录**。多个工作区并列，各自独立解析。

## 边界

- 解析器**不写文件**。写是编辑节点的事。
- 解析器**不缓存真源**。可以缓存解析结果，但缓存丢了必须能重算出同一棵树。
- 解析器**不修正结构**。目录不合法（`X-子节点/` 找不到对应的 `X.md`）就报出来，不自动补文件。
- 不解析 Markdown 语义（不建 AST 给画布用）。画布要的是树和正文，不是语法树。

## 验证

- 任意合法目录 → 解析 → 用 id 还原路径，能逐字节对回原目录结构。
- 改一个文件的标题/状态，重解析后只有该节点变，其余节点 id 和内容不变。
- 删除一个叶子文件，父节点 children 少一个，其他不变。
