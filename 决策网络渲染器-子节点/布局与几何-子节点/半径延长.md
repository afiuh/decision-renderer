# 半径延长

**父级**：[布局与几何](../布局与几何.md)

## 问题

每个节点展开后，子节点要绕它排一圈。如果父到子的距离固定（比如统一 200px），深度一大，子节点的圆就会盖住祖先卡片——因为展开的子树本身占了一大片圆。

## 约束

给每个节点算一个**占地半径** `circleRadius`：

```
叶子（或折叠）：circleRadius = NODE
展开：circleRadius = max(所有子节点的 circleRadius) + NODE + GAP
```

父到某个子节点的连线长度 = 该子节点的 `circleRadius` + NODE + GAP。

于是父节点离每个子节点都足够远，远到子节点整片圆都不碰父节点。深度越大半径越长——这是必要的，不是 bug。

`NODE` = 卡片外接圆半径（约卡片宽度的一半），`GAP` = 视觉间隙。两个常数由渲染层的卡片尺寸决定，不写死在布局里。

## 边界

- 不用统一半径。统一半径在展开深度不一时必然重叠。
- 不做"压缩"（把长边折回来）。圆形扩散的代价就是半径随深度增长，接受它，用缩放看全貌。
- 不因为"太远"就截断。截断 = 重叠。

## 验证

- 展开三层、每层 3 个子节点：最外层卡片与根卡片不重叠。
- 折叠最外层后，上一层连线长度按新 circleRadius 缩短（不是保持旧长度）。
