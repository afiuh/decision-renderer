# 半径下限

**父级**：[布局与几何](../布局与几何.md)

## 问题

半径由弧长反推（见[圆形扩散](./圆形扩散.md)）。多数情况下这个半径足够大，子节点的圆不会碰到父节点。

但有一个例外：**只有一个子节点、且它展开得很深**。弧长反推只给出 `2×circleRadius / 2π ≈ circleRadius/π`，远小于 circleRadius 本身——子节点的圆会把父节点整个盖住。

## 约束

基础半径 `r0` 是父节点统一的（所有连线默认等长，角度按它分配）。实际连线长度逐条算，只有展开的那条会超过 `r0`：

```
r0 = Σ(2 × nodeRadius_i + GAP) / 2π          // 基础半径：所有连线默认等长

r_i = max(r0, nodeRadius_i + parentRadius + GAP)   // 每条连线的实际长度
```

只有展开且 `circleRadius` 大到放不下的那一条，`r_i` 才会超过 `r0`；其余子节点仍是 `r0`。

- `nodeRadius_i`：展开节点 = 它的 circleRadius；叶子 = 卡片外接圆半径。
- `parentRadius`：父节点卡片的外接圆半径。

`circleRadius` 仍然递归：

```
叶子 / 折叠：circleRadius = 卡片外接圆半径
展开：circleRadius = max(子节点 circleRadius) + 卡片外接圆半径 + GAP
```

它只回答一个问题：**这个节点展开后，整片圆占多大地方**。父节点用这个数决定"要给这个子节点留多宽的角度、多长的半径"。

## 边界

- 不做"压缩"（把长边折回来）。深度大半径就大，用缩放看全貌。
- 不因为"太远"截断半径。截断 = 重叠。
- 不把 circleRadius 当成"连线长度"直接加。连线长度是反推出来的，circleRadius 只参与下限。

## 验证

- 单个子节点、展开三层：父节点卡片不被任何子孙的圆覆盖，那一条连线被延长。
- 未展开时，同一父节点的任意两条连线长度相等；展开一个分支时，只有那一条变长，其余长度不变。
- 展开一个深分支：只有它那一条连线延长，其他子节点位置和长度不变。
- 折叠该分支：那一条回到 `r0`，所有连线恢复等长。
