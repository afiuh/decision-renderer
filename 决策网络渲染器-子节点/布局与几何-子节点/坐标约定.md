# 坐标约定

**父级**：[布局与几何](../布局与几何.md)

## 约定

| 层 | 坐标 | 说明 |
|---|---|---|
| 布局（纯函数） | **中心坐标** `{x, y}` | 几何计算用中心，角度/半径都绕中心算 |
| React Flow 节点 | **左上角** `position` | 转换：`position = center - (w/2, h/2)` |
| 内容节点 | **相对父节点** | `parentId` + 相对父节点左上角的 `position`，随父节点移动/缩放 |

## 为什么用中心

角度和半径绕中心才有意义。布局层若用左上角，每次算完都要反推中心，卡片宽高不一致时容易错。中心只在"交给 React Flow"那一刻转成左上角。

## 边界

- 卡片宽高由渲染层提供，布局层不硬编码。拿不到真实尺寸时用约定尺寸，但只能有一个来源。
- 内容节点位置是**相对**的，不参与树的几何计算，不占子树占位。

## 验证

- 缩放画布，内容节点与父节点的相对位置不变。
- 拖动父节点，内容节点跟着走，不漂移。
