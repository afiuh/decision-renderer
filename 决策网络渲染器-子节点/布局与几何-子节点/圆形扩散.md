# 圆形扩散

**父级**：[布局与几何](../布局与几何.md)

## 角度

一个展开节点有 n 个子节点，每个子节点分到 `2π / n` 的扇区，角度取扇区中点：

```
theta_i = -π/2 + (i + 0.5) × (2π / n)
```

从正上方（-90°）开始顺时针排。第一个子节点永远在正上方——同一棵树每次展开朝向一致，人不会"上次在这边，这次跑那边"。

## 占位

占位不是"子节点个数"，是**子树展开后的可见节点数**：

- 折叠的子树：占位 = 1（它自己）
- 展开的子树：占位 = 1 + 所有子节点占位之和

父节点按子节点的占位比例分扇区：

```
span_i = 2π × 占位_i / Σ占位
```

## 边界

- 不为"好看"做角度微调（错开、抖动、黄金角）。角度只由占位决定，可预测。
- 不做多层同心圆（每层一个环）。每个节点有自己的圆，圆的大小由子树决定。

## 验证

- 占位 3 和 1 的两个子树，扇区比 3:1。
- 折叠一个大子树后，剩余子树按新占位重新分配扇区。
