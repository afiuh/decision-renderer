# 圆形扩散

**父级**：[布局与几何](../布局与几何.md)

## 核心：按弧长铺满一圈

不是"n 个子节点均分 360°"。每个子节点在父圆上占的**弧长**由它自己的外接圆决定：

```
弧长_i = 2 × nodeRadius_i + GAP
nodeRadius_i = 展开节点 ? circleRadius_i : 卡片外接圆半径
```

所有子节点的弧长加起来，正好铺满父圆一圈：

```
2π × r = Σ(2 × nodeRadius_i + GAP)
r = Σ(2 × nodeRadius_i + GAP) / 2π
```

**默认所有连线等长**：所有子节点共用基础半径 `r0`，这就是"一致"的状态。

**唯一的例外**：某个子节点展开后，它的整片圆（circleRadius）离父节点太近会重叠，就**只把这一条连线延长**，其他子节点原地不动。折叠后它回到 `r0`，所有连线重新等长。

于是：

- 子节点多 → 半径大；子节点少 → 半径小。
- 展开的子节点（nodeRadius 大）独占一大段弧——它的整片圆不会和兄弟挤在一起。
- 两个节点框在圆周上永远不重叠，从中心发出的连线也不交叉。

## 角度

从正上方（-90°）开始顺时针，按**权重降序**排（权重 = 子树占位，折叠算 1）：

```
theta_i = -π/2 + Σ_{j<i} 弧长_j / r + 弧长_i / (2r)
```

权重大的靠近正上方——人一眼看到的是最重要的分支。

## 为什么不是均分

均分只保证"每个子节点一样大的扇区"，不保证框不重叠：两个宽框挤在 15° 的扇区里必然相交，窄框之间又留出大片空白。

按弧长分配把"框的实际宽度"变成"占的角度"，拥挤和空洞同时消失。

## 边界

- 不用均分，也不用"占位比例 × 固定半径"。半径由弧长反推，不是先定的。
- 不做角度微调（抖动、黄金角）。角度完全由弧长决定，可预测。
- 不做多层同心圆。

## 验证

- 任意子节点组合：相邻两个框在圆周上的间隙 ≥ GAP，不重叠。
- 未展开时，同一父节点下所有连线长度**严格相等**。
- 展开一个深分支：只有它的连线变长，其他子节点位置和长度都不变；折叠后全部回到等长。
- 展开一个子节点（nodeRadius 变大）：父圆半径变大，该子节点扇区变宽，兄弟被推开但不重叠。
- 同一输入两次布局，角度和半径完全一致。
