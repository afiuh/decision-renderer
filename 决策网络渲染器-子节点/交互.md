# 交互

**父级**：[决策网络渲染器](../决策网络渲染器.md)

## 约束

### 拖动 = 沿圆周旋转

节点不能自由拖。拖动改变的是**它在父节点圆上的角度**，半径保持不变：

- 拖到哪，角度就是"从父节点中心指向鼠标"的角度。
- 半径由布局给定（见半径延长），拖动不改半径。
- 拖动父节点，所有子孙按位移 delta 跟随——整棵子树刚性平移，相对形状不变。

### 折叠 / 展开

- 折叠：该节点变成叶子，子树从画布消失，父节点按新占位重算布局。
- 展开：子树出现，按占位重新分配扇区。
- **用户拖过的节点保留角度**；没拖过的按算法排。

### 视口（PS 机制）

| 操作 | 行为 |
|---|---|
| **空格 + 左键拖动** | 平移（临时抓手；按住期间节点不响应点击） |
| **滚轮** | 平移，不缩放 |
| **Alt + 滚轮** | 以鼠标位置为中心缩放 |
| 中键 / 右键拖动 | 平移 |
| **Ctrl/Cmd + 0** | 适合屏幕 |
| **Ctrl/Cmd + 1** | 100% |
| 双击 | 不缩放 |

- 树结构变化（展开/折叠/新建/删除）后自动 fit，让人看到全貌。
- 用户手动缩放/平移后，不因为无关更新打断视口。
- fit 时机由"节点已渲染"决定，不用固定延时猜。

## 边界

- **不接管 React Flow 的拖拽状态**。不用 `queueMicrotask` 之类手段在拖拽中途改写位置——那会和内置拖拽打架。
- **不做自由拖动 + 自动吸附**。拖动语义就是旋转，没有"拖出去再吸回来"。
- **不做节点间推挤**。圆形布局本身不重叠；推挤与"保持半径"冲突。
- **滚轮不直接缩放**。PS 里滚轮是滚动，缩放必须带修饰键；直接滚轮缩放会让人在平移时误缩放。

## 验证

- 拖一个父节点绕一圈：子孙相对位置不变，半径不变。
- 拖动后展开/折叠别的分支：被拖过的节点角度不变。
- 树变化后 fit 一次到位，不出现"先偏右再跳正"。
