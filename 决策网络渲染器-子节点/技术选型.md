# 技术选型

**父级**：[决策网络渲染器](../决策网络渲染器.md)

## 这个模块负责什么

选技术：整体形态、Web 框架、画布、Markdown 渲染、文件监听、存储、通信。

## 整体形态（2026-11-06 决定）

**网页 + 本地 Node 服务**，不做独立软件（先）。

```
浏览器（画布 UI，React + web-kit）
  ↕ HTTP / SSE
Node 服务（fs 读写 decisions/）
```

**理由**：

| 理由 | 说明 |
|---|---|
| 最快 | React + web-kit 直接复用 |
| AI 接口天然 | AI 调 HTTP 就能看树/改节点 |
| 不用打包 | 浏览器打开就能用 |
| 文件访问 | Node 服务有完整 `fs` 权限 |

**以后**：需要"独立软件"感觉时用 Tauri 包装（Web 代码不变）。

## 具体选型

| 项 | 结论 | 状态 |
|---|---|---|
| Web 框架 | React + web-kit（母体） | 定 |
| 架构 | 网页 + 本地 Node 服务 | 定 |
| 通信 | HTTP（读写）+ SSE（文件变化推送） | 定 |
| 画布 | 待定（React Flow / 自写 transform） | 待定 |
| Markdown 渲染 | 待定（react-markdown / markdown-it） | 待定 |
| 文件监听 | chokidar | 待定 |
| 布局存储 | `layout.json`（位置与结构分离） | 待定 |
| 独立软件 | Tauri（以后） | 待定 |

## 关键约束

- **文件树是真源**：画布是它的视图，改画布 = 改文件树
- **双向同步**：文件变化 → 画布更新；画布操作 → 写文件
- **防循环**：写文件时标记来源，监听忽略自己触发的
