# 技术选型

**父级**：[决策网络渲染器](../决策网络渲染器.md)

## 整体形态

**浏览器 + 本地 Node 服务**，不做独立软件。

```
浏览器（React）
  ↕ HTTP / WebSocket
Node 服务（fs 读写决策目录）
```

| 选择 | 理由 |
|---|---|
| 网页而不是桌面 | React 生态直接复用；AI 调 HTTP 天然；不用打包分发 |
| 本地服务而不是纯前端 | 浏览器不能直接读写任意目录；服务端有完整 `fs` |
| WebSocket 而不是轮询 | 文件变化要即时反映到画布 |

以后要"独立软件"的体感，用 Tauri 包一层，Web 代码不动。

## 选型

| 层 | 选型 | 为什么 |
|---|---|---|
| 画布 | **React Flow**（`@xyflow/react`，MIT） | 节点/连线/缩放/拖拽/自定义节点现成；Excalidraw 偏白板，tldraw 商用需授权 |
| Markdown 渲染 | **react-markdown**（MIT） | 够用、可控，不引入编辑器内核 |
| 代码高亮 | **shiki**（MIT） | 主题一致，构建期/运行时都能用 |
| 文件监听 | **chokidar**（MIT） | 跨平台、去抖成熟 |
| 编辑器 | **CodeMirror 6**（MIT） | 轻、稳、Markdown 模式够用；Milkdown/TipTap 是 WYSIWYG，已排除 |
| 写回 | **remark**（MIT） | 只改内容，不重排结构 |
| HTTP | **Fastify**（MIT） | 快、插件化、静态托管一个包解决 |
| MCP | `@modelcontextprotocol/sdk`（MIT） | 官方实现 |

## 边界

- **不引入第二套状态管理**。画布状态（展开集、拖动位置、视口）就是 React 状态 + 布局纯函数，不上 Redux/Zustand。
- **不引入 UI 组件库**。卡片、菜单、搜索框自己写，避免样式和 React Flow 打架。
- **不为"以后可能换"做抽象**。布局和解析已经是纯函数，够了；不再加 provider/adapter 层。

## 验证

- 依赖树里没有 GPL/AGPL。
- 生产构建产物能由一个 Fastify 进程同时服务静态页和 API。
