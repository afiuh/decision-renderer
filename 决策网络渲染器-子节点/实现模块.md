# 实现模块

**父级**：[决策网络渲染器](../决策网络渲染器.md)

## 这个模块负责什么

把决策网络变成协作界面的具体实现：解析目录、渲染视图、编辑节点、暴露 AI 接口、同步文件变化。

## 这一级拆成 N 个子模块（待展开）

| 子模块 | 负责什么 |
|---|---|
| 解析 | 目录 → 节点树（标题 / 状态 / 子节点） |
| 视图 | 五区布局（D 过滤 / C 树 / A 内容 / B 操作 / E 对比） |
| 编辑 | 改节点（保持 Markdown 格式） |
| AI 接口 | 暴露树 / 节点 / 搜索，AI 不读文件 |
| 同步 | 文件变化 → 树更新 |

> 待讨论：这五个是否都要，先做哪几个。
