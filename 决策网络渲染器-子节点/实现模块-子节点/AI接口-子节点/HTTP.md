# HTTP

**父级**：[AI 接口](../AI接口.md)

## 这个模块负责什么

暴露 HTTP 接口给 AI（读树 / 读节点 / 搜索 / 写节点）。

## 选型

Fastify（MIT）。

## 接口（草案）

| 方法 | 路径 | 作用 | 状态 |
|---|---|---|---|
| GET | `/api/tree` | 节点树 | ✅ |
| GET | `/api/node/:id` | 节点内容 | ✅ |
| POST | `/api/node/:id` | 写节点 | ✅ |
| POST | `/api/node` | 新建子节点（`{ parent, title }`） | ✅ |
| GET | `/api/search?q=` | 全文搜索（需 URL 编码） | ✅ |

## 状态（2026-11-06）

✅ 全部接口可用，已实测：
- 搜索"插件" → 返回命中（snippet）
- 新建"测试子节点" → 写 `决策网络渲染器-子节点/测试子节点.md`（已清理）
