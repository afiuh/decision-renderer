# 信息渲染

**父级**：[实现模块](../实现模块.md)

## 这个模块负责什么

把决策网络（文件夹 + Markdown）解析成节点树，并渲染成可看的界面（树 + 内容 + 状态）。

## 包含

| 部分 | 说明 |
|---|---|
| 解析 | 目录 → 节点树（标题 / 状态 / 子节点） |
| 视图 | 五区布局（D 过滤 / C 树 / A 内容 / B 操作 / E 对比） |
| 同步 | 文件变化 → 树更新 |

## 前端复用 web-kit

| 区 | 内容 |
|---|---|
| **A** | 无限画布（React Flow：节点 + 连线，pan/zoom） |
| **B** | 操作（新建节点 / 视图控制） |
| **C/D/E** | 空着（不需要树/过滤/并行） |

**画布内**：节点（卡片，可拖拽）+ 连线（文件树父子关系，自动）+ 窗口（点节点展开，可拖拽/缩放，Markdown）。
