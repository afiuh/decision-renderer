# 信息渲染

**父级**：[实现模块](../实现模块.md)

## 这个模块负责什么

把决策网络（文件夹 + Markdown）解析成节点树，并渲染成可看的界面（树 + 内容 + 状态）。

## 这一级拆成三个子模块

| 子模块 | 负责什么 |
|---|---|
| [解析](./信息渲染-子节点/解析.md) | 目录 → 节点树 + 边 |
| [视图](./信息渲染-子节点/视图.md) | 无限画布：节点 + 连线 + 窗口 |
| [同步](./信息渲染-子节点/同步.md) | 文件树 ↔ 画布双向同步 |

## 前端复用 web-kit

| 区 | 内容 |
|---|---|
| **A** | 无限画布（React Flow：节点 + 连线，pan/zoom） |
| **B** | 操作（新建节点 / 视图控制） |
| **C/D/E** | 空着（不需要树/过滤/并行） |

**画布内**：节点（卡片，可拖拽）+ 连线（文件树父子关系，自动）+ 窗口（点节点展开，可拖拽/缩放，Markdown）。
