# 编辑

**父级**：[实现模块](../实现模块.md)

## 这个模块负责什么

改节点（保持 Markdown 格式）：改内容 / 改状态 / 新建子节点 / 移动 / 删除。

## 这一级拆成三个子模块

| 子模块 | 负责什么 |
|---|---|
| [编辑器](./编辑-子节点/编辑器.md) | 窗口内编辑（CodeMirror） |
| [写回](./编辑-子节点/写回.md) | 保持 Markdown 格式写回（remark） |
| [冲突](./编辑-子节点/冲突.md) | 外部修改 vs 画布编辑 |
