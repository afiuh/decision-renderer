# 视图

**父级**：[信息渲染](../信息渲染.md)

## 这个模块负责什么

把节点树渲染成无限画布：节点卡片 + 连线 + 内容窗口。

## 组成

| 部分 | 说明 |
|---|---|
| 画布 | React Flow（pan/zoom，无限） |
| 节点 | 卡片（标题 + 状态），可拖拽 |
| 连线 | 父子关系，自动（来自解析） |
| 窗口 | 点节点展开（画布坐标，可拖拽/缩放，Markdown） |

## 连线（节点 ↔ 节点）

| 项 | 规则 |
|---|---|
| **方向** | 父 → 子 |
| **起止** | **边到边**（父节点底部/右侧 → 子节点顶部/左侧），**不穿过节点** |
| **层级** | 线在**最底层**（z-index 最低），节点/窗口在上 |
| **样式** | 贝塞尔曲线（平滑），细线（1px） |
| **不遮挡** | 线不穿过节点（边到边）+ 窗口位置避开线 |

## 碰撞逻辑

| 碰撞 | 规则 |
|---|---|
| **节点 ↔ 节点** | 不重叠；拖拽时**推挤**（对方让开），边距 8px |
| **节点 ↔ 窗口** | 窗口打开时找**空位**（不遮挡节点）；拖窗口时推挤节点 |
| **窗口 ↔ 窗口** | 不重叠；拖拽时推挤 |

### 检测

矩形相交（AABB）：

```
x1 < x2 + w2 && x1 + w1 > x2 && y1 < y2 + h2 && y1 + h1 > y2
```

### 初始布局

dagre / elk 自动布局（树形，保证不重叠）。

### 拖拽

目标位置与已有元素相交 → **推挤**（把对方推开），边距 8px。

### 窗口打开

在节点右侧找**最近的空位**（放得下就放，不遮挡节点/线）。

## 布局存储

- 初始：自动布局
- 手动：拖拽节点 → 位置存 `layout.json`
- 连线永远跟文件树（不跟位置）

## 更新（2026-11-06 深夜）——圆形扩散

**布局**（词块树方式）：

| 项 | 规则 |
|---|---|
| **形状** | 圆形扩散（根在中心，子节点围绕） |
| **角度** | 全圆 360°，按占位比例（`占位/总占位 × 2π`） |
| **半径** | `max(150, 占位 × 200 / 2π)`——节点少半径小，节点多半径大 |
| **占位** | 子树节点数（折叠算 1） |
| **拖动** | **沿圆周旋转**（保持半径，角度自由），不是自由拖动 |
| **展开/折叠** | 新节点用布局位置，已有节点保留用户拖动的位置 |

**内容节点**：

| 项 | 规则 |
|---|---|
| **跟随** | `parentId`（原节点 id），自动跟随（不需要边） |
| **位置** | 相对父节点（220, -60） |
| **大小** | 520×420（NodeResizer 可缩放） |

**其他**：

- 多工作区（dshiunx / decision-renderer），切换重连 WS
- 只显示有子节点的根（`核心战略`），元数据/归档不显示
- `fitView`：`maxZoom: 1`（不放大），展开后重新 fit

## 更新（2026-11-07）——半径延长 + 子节点跟随

**半径延长**（`circleRadius` 递归）：

| 节点 | circleRadius |
|---|---|
| 叶子（折叠） | 140（卡片宽） |
| 展开节点 | `max(子节点 circleRadius) + 140 + 40` |

- 父节点到上一级的距离 = 子节点的最大 circleRadius + 卡片 + 间隙（**延长**，确保子节点的圆不覆盖祖先）

**拖动**：

| 项 | 规则 |
|---|---|
| 沿圆周旋转 | 保持半径，角度自由（`onNodeDrag` + `queueMicrotask` 覆盖 React Flow 的 `onNodesChange`） |
| **子节点跟随** | 拖动父节点 → 子孙按 `delta`（新位置 - `dragStart`）平移（`radialLayout` 返回 `descendants`） |
| 内容节点 | `parentId` 跟随原节点（不需要边） |

**已知问题**：

- `fitView` 延迟 200ms 可能不够（子节点未渲染完）→ 改 500ms
- 拖动距离大时子节点可能超出画布（无限画布，用户自己缩放）
- `Canvas.tsx` 229 行（待拆）
- `NODE_W`/`NODE_H`（180/56）vs 卡片 140（不一致）

## 计算位置模块（`layout/radial.ts`，2026-11-07）

**职责**：纯函数，输入 `(tree, expanded)`，输出 `LayoutResult`（无 React 依赖）。

**输出**：

| 字段 | 含义 |
|---|---|
| `positions` | 节点**中心坐标**（`{ x, y }`） |
| `parents` | 子 → 父（id 映射） |
| `radii` | 子节点到父节点的**连线长度** |
| `descendants` | 每个节点的**所有子孙**（拖动跟随） |

**规则**：

| 项 | 规则 |
|---|---|
| **角度** | `theta = -90° + (i + 0.5) × span`（每个子节点直接算，`span = 2π/n`，120° 均匀） |
| **连线长度** | **每个子节点单独**：`r = circleRadius(child) + NODE + GAP` |
| **`circleRadius`** | 递归：叶子 = `NODE`；展开 = `max(子节点 circleRadius) + NODE + GAP`（**延长**，防重叠） |
| **根** | 在中心 `(0, 0)`；多个根时围绕中心 |
| **常数** | `NODE = 140`（卡片宽）、`GAP = 40`（间隙） |

**为什么这样**：

- 全圆（360°）——每个节点展开，子节点围绕它（像词块树）
- 半径延长——子节点展开后，它的"占地面积"（`circleRadius`）变大 → 连线变长 → 子节点的圆不覆盖祖先
- 每个子节点单独——展开的连线长（`circleRadius` 大），折叠的短

**消费方**：

- `useNodes`：中心 → 左上角（`- NODE_W/2, - NODE_H/2`）
- `useDrag`：`parents`（找父节点）、`radii`（保持半径）、`descendants`（子节点跟随）
