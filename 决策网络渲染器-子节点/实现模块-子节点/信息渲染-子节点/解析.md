# 解析

**父级**：[信息渲染](../信息渲染.md)

## 这个模块负责什么

遍历 `decisions/` 目录，产出节点树：每个节点（文件）的标题、路径、状态、子节点；以及边（父子关系）。

## 输入 / 输出

| 输入 | 输出 |
|---|---|
| 目录路径 | 节点列表 `{ id, title, path, status, children }` + 边列表 `{ from, to }` |

## 规则

- 一个 `.md` = 一个节点；`X-子节点/` = 它的子节点
- 标题取第一个 `# `
- 状态从正文提取（`## 状态` 段或 ✅/❌/⏳）
- 归档区（`历史讨论-子节点/`）只读、不参与演化
