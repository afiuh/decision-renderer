# AI 接口

**父级**：[决策网络渲染器](../决策网络渲染器.md)

## 约束

AI 不读文件。它要的东西，接口必须能直接给。

| 能力 | 说明 |
|---|---|
| 列出工作区 | 有哪些决策网络根 |
| 读树 | 节点树（id / 标题 / 状态 / 子节点），可指定深度 |
| 读节点 | 单个节点的 Markdown 正文 + 路径 + 状态 |
| 搜索 | 全文搜索，返回命中节点 + 片段 |
| 新建节点 | 指定父节点 + 标题 |
| 写节点 | 整篇写回（与画布内编辑走同一条写回路径） |

两条通道，同一套能力：

- **HTTP**：给任意 AI / 脚本用，浏览器和 CLI 都能调。
- **MCP**：给支持 MCP 的客户端用（stdio），工具名直接对应上表。

## 边界

- **不暴露任意路径读写**。只能读写工作区内的决策目录。
- **不做鉴权**。本地服务，监听回环地址。
- **不做增量补丁接口**。写就是整篇写；要改一句就传整篇。
- **接口不返回文件系统细节**（mtime 除外，可用于判断"是否变过"）。

## 验证

- 只调接口完成闭环：搜索找到节点 → 读正文 → 改一句 → 写回 → 再读确认。
- 人和 AI 同时改不同节点，互不影响。
- MCP 工具列表与 HTTP 路由一一对应，没有只有一边有的能力。
