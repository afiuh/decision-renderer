# 编辑

**父级**：[决策网络渲染器](../决策网络渲染器.md)

## 约束

- **编辑在内容节点里**：预览 / 编辑切换，编辑用 CodeMirror（Markdown）。
- **保存 = 写回同一个文件**，保持 Markdown 格式：只改用户改的内容，不重排标题层级、不重写列表符号、不碰 frontmatter。
- **新建子节点** = 在父节点的 `X-子节点/` 下建文件（需要时建目录），写最小骨架（标题 + 父级链接）。
- **重命名** = 改文件名（和对应目录名）。不改正文里的引用——引用更新是人的事，工具最多提示。
- **删除** = 删文件；有子节点时先要求确认，不级联删目录。

## 边界

- **不做冲突处理**。不做 mtime 检测、不加锁、不做 CRDT、不弹"文件已被外部修改"。人和 AI 不会同时改同一个文件——这是使用约定。真撞了，git 留下两边的版本。
- **不做 WYSIWYG**。编辑就是改 Markdown 源码。
- **不自动格式化**。保存后的 diff 只应包含用户实际改动。

## 验证

- 改一句话保存：`git diff` 只有那一行。
- 外部（编辑器/AI）改文件：画布在去抖窗口内更新，不需要手动刷新。
- 新建子节点后，父节点在画布上多一个子节点，磁盘上多一个文件。
